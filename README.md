# Portfolio — 5 separate pages

- index.html         -> Home
- projects.html       -> Projects
- about.html          -> About
- off-the-screen.html -> Off The Screen
- say-hi.html         -> Say Hi

All five share the same nav bar, so every page links to every other page.

## Before publishing
1. Search "yourname.dev" in each file — swap for your real name (appears in the nav logo)
2. In index.html — your real name and tagline in the hero
3. In about.html — the timeline years are placeholders; the skills lists
   reflect what's been covered so far, adjust freely
4. In off-the-screen.html — swap the 3 placeholder photos for real ones
5. In say-hi.html — your real WhatsApp number and social links

## Publishing
Drag this whole folder into Netlify's Deploys tab — all 5 pages and the
images folder need to go live together.
